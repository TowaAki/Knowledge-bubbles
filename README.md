# 知识气泡 (Knowledge Bubbles)

一个基于纯前端、无需后端的可视化名词知识库。所有知识条目以轻盈漂浮的玻璃气泡呈现，点击气泡即可查看详细解释。

无需安装依赖，无需构建，下载单个 HTML 文件后双击即可使用。

> 公式渲染使用 jsDelivr 上的 KaTeX CDN，首次打开时需要联网加载。断网时页面仍可正常使用，公式会退化为原始 LaTeX 文本。

## ✨ 功能特点

- **气泡可视化**：半透明玻璃质感气泡、柔和阴影、缓慢漂浮与碰撞避让
- **自动密度适配**：气泡超过 30 个时自动缩小尺寸，文字最低保持 12px
- **分页浏览**：超过 40 个词条时自动分页，每页最多渲染 40 个气泡
- **聚焦动效**：点击气泡后其余气泡淡出至 0.2，目标气泡放大移动到左上角
- **即时搜索**：匹配气泡高亮，不匹配气泡自动淡出，可自动跳转到匹配所在页
- **知识详情**：大标题、配图、Markdown 解释、词条编辑、删除二次确认
- **编辑词条**：自动回填现有内容，保存后同步刷新气泡与详情，保留原气泡颜色和大小
- **新增词条**：名词、详细解释、网络配图链接、自动分配马卡龙色
- **导入 / 导出**：支持 JSON 备份，合并导入或覆盖导入
- **本地存储**：使用浏览器 `localStorage` 自动保存
- **数学公式**：通过 KaTeX CDN 渲染行内与块级 LaTeX 公式，支持快捷插入
- **外观 DIY**：浅蓝 / 纯白 / 暗黑星空预设背景，支持网络壁纸和本地壁纸上传
- **气泡风格**：玻璃泡泡、扁平极简、拟物肥皂泡三套视觉方案
- **轻量压缩**：本地壁纸自动缩放至最长边 2560px，优先导出 WebP（质量 0.8）
- **响应式布局**：桌面与手机端均可使用
- **零构建**：不使用框架，也不需要 npm 构建
- **离线可用**：除公式渲染外，其余功能断网也能运行；KaTeX 加载失败时公式按原文显示

## 🚀 如何运行

### 方式一：直接运行

1. 下载 `knowledge-bubbles.html`
2. 双击文件，使用浏览器打开
3. 开始添加你的知识词条

### 方式二：克隆仓库后运行

```bash
git clone https://github.com/<your-name>/<your-repo>.git
cd <your-repo>
```

然后直接双击 `knowledge-bubbles.html`，或在浏览器中打开该文件。

无需运行 `npm install`、`npm run dev` 或任何构建命令。

## 💾 数据存储与安全警告

> [!WARNING]
> **所有数据仅保存在当前浏览器的 LocalStorage 中，不会上传到任何服务器。**
>
> 更换电脑、更换浏览器、清理浏览器缓存、使用无痕模式或重装系统前，请务必先点击页面右上角的 **“导出备份”**，将数据保存为 `knowledge_backup.json` 文件。
>
> 一旦浏览器缓存被清理，本地数据将无法恢复。建议定期导出备份。

- 存储键名：`knowledge-bubble-library-v1`
- 外观设置使用独立键名：`kb-appearance-settings`，不会进入知识库导出 JSON
- 首次访问且本地没有数据时，会自动注入 5 个示例词条
- 已经有数据时刷新页面不会覆盖现有内容
- 本地数据损坏时，程序不会写入示例数据覆盖原内容，并会保留一份带 `-corrupt-` 后缀的备份键
- 底部左侧的垃圾桶小按钮可以清空当前浏览器内的全部知识条目，操作前会弹出确认提示

## 📖 使用说明

### 搜索

在顶部搜索框输入名词或解释中的关键词：

- 匹配的气泡会高亮
- 不匹配的气泡会淡出
- 当匹配项不在当前页时，会自动跳转到第一个匹配所在页
- 支持 `Ctrl + K`（macOS 为 `⌘ + K`）快速聚焦搜索框
- 按 `Esc` 清除搜索

### 分页与聚焦

- 词条超过 40 个时，底部右侧会显示分页箭头和页码
- 每次只渲染当前页最多 40 个气泡，保证动画性能
- 气泡超过 30 个时自动缩小，文字不会小于 12px
- 点击气泡时，其余气泡淡化到 0.2，目标气泡会放大并移动到左上角，然后打开详情
- 关闭详情后，目标气泡会平滑回到原位，其他气泡恢复显示

### 查看、编辑与删除

点击气泡打开详情卡片，可查看：

- 大号名词标题
- 配图（加载失败时显示默认封面）
- Markdown 格式的详细解释

详情卡片右下角提供：

- **编辑该词条**：打开已回填的表单，保存后同步更新气泡和当前详情
- **删除该词条**：删除前需要二次确认，并可在底部提示条中撤销

编辑词条时会保留气泡原有的颜色和大小，不会因为名词长度变化而重新调整气泡尺寸。

### 数学公式

详细解释支持 LaTeX 公式，由 KaTeX 自动渲染：

- 行内公式：`$...$` 或 `\(...\)`
- 块级公式：`$$...$$` 或 `\[...\]`

添加或编辑词条时，可以在“详细解释”输入框上方使用快捷按钮：

- **行内公式**：插入 `$ $`
- **块级公式**：插入 `$$\n\n$$`
- **分数**：插入 `\frac{分子}{分母}`
- **上标**：插入 `^{}`

如果公式语法有误或缺少闭合定界符，页面不会崩溃，会尽量按原文显示。

### 外观设置

点击顶部操作栏的 **⚙ 设置** 打开“外观设置”面板：

- **预设背景**：浅蓝渐变、纯白极简、暗黑星空
- **网络壁纸**：粘贴图片链接后直接使用原图
- **本地壁纸**：上传图片后自动压缩，最长边 2560px，优先 WebP，质量 0.8
- **气泡风格**：玻璃泡泡、扁平极简、拟物肥皂泡

本地壁纸压缩后如果仍超过 2MB，页面会提示更换图片；如果浏览器 LocalStorage 容量不足，会自动回滚并保留原来的背景。

外观设置保存在独立键 `kb-appearance-settings` 中，**不会**包含在导出的知识库 JSON 中。知识库正文单条最多 10000 字。

### 导入与导出

- **导出备份**：下载 `knowledge_backup.json`
- **导入数据**：支持合并导入或覆盖导入
  - 合并：跳过与当前知识库同名的词条
  - 覆盖：清空当前数据并替换为文件内容

### 清空本地数据

点击左下角名词计数旁的垃圾桶图标：

- 会弹出原生警告确认框
- 确认后清空当前浏览器中的全部知识条目并刷新页面
- 建议操作前先导出备份

## 🌐 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库
2. 将 `knowledge-bubbles.html` 重命名为 `index.html`
3. 把 `index.html` 和 `README.md` 上传到仓库根目录
4. 打开仓库的 **Settings → Pages**
5. 在 **Build and deployment** 中选择 **Deploy from a branch**
6. 分支选择 `main`，目录选择 `/ (root)`，点击 **Save**
7. 等待部署完成后访问：

```text
https://<your-github-username>.github.io/<your-repository-name>/
```

> GitHub Pages 只能托管静态文件；本项目不需要后端服务，因此非常适合直接部署。

## 🧱 技术栈

- 原生 HTML / CSS / JavaScript
- CSS `backdrop-filter` 玻璃效果
- 原生 DOM 气泡渲染 + 自定义物理漂浮、边界回弹与碰撞避让
- Canvas 2D 文本测量
- `localStorage` 数据持久化
- 内置安全 Markdown 解析器
- KaTeX + auto-render（jsDelivr CDN）渲染数学公式

## 🔒 数据格式

导出的 `knowledge_backup.json` 是一个数组，每个词条包含：

```json
[
  {
    "id": "unique-id",
    "name": "深度学习模型",
    "desc": "**深度学习模型**是机器学习的一个分支。",
    "imageUrl": "https://example.com/cover.jpg",
    "color": "#BAE6FD",
    "sizeBasis": "深度学习"
  }
]
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识 |
| `name` | 名词名称 |
| `desc` | Markdown 格式的详细解释（最多 10000 字） |
| `imageUrl` | 网络图片链接，可为空 |
| `color` | 气泡颜色（马卡龙浅色板） |
| `sizeBasis` | 可选，用于编辑后保持气泡大小不变 |

## 🧪 浏览器兼容

推荐使用现代版本的 Chrome、Edge、Safari 或 Firefox。

`backdrop-filter` 在部分旧版浏览器中可能不受支持，但气泡仍会保留半透明底色、白色边框和文字可读性。
